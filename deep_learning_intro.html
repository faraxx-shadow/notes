⚡ Activation Functions

Activation functions introduce non-linearity to neural networks, enabling them to learn complex patterns.

🎮 Interactive Activation Functions

# Common activation functions in TensorFlow import tensorflow as tf # ReLU: f(x) = max(0, x) relu_output = tf.nn.relu([-2, -1, 0, 1, 2]) # Sigmoid: f(x) = 1 / (1 + e^(-x)) sigmoid_output = tf.nn.sigmoid([-2, -1, 0, 1, 2]) # Tanh: f(x) = (e^x - e^(-x)) / (e^x + e^(-x)) tanh_output = tf.nn.tanh([-2, -1, 0, 1, 2])

🖼️ Convolutional Neural Networks (CNNs)

CNNs are specialized neural networks for processing grid-like data such as images. They use convolutional layers to detect features.

import tensorflow as tf from tensorflow import keras # CNN for image classification model = keras.Sequential([ keras.layers.Conv2D(32, (3, 3), activation='relu', input_shape=(28, 28, 1)), keras.layers.MaxPooling2D((2, 2)), keras.layers.Conv2D(64, (3, 3), activation='relu'), keras.layers.MaxPooling2D((2, 2)), keras.layers.Flatten(), keras.layers.Dense(64, activation='relu'), keras.layers.Dense(10, activation='softmax') ]) model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])

🔍 CNN Components

Convolutional Layers: Apply filters to detect features like edges, textures

Pooling Layers: Reduce spatial dimensions and computational load

Fully Connected Layers: Perform final classification

🔄 Recurrent Neural Networks (RNNs)

RNNs are designed for sequential data, maintaining memory of previous inputs through recurrent connections.

import tensorflow as tf from tensorflow import keras # LSTM for sequence prediction model = keras.Sequential([ keras.layers.LSTM(50, return_sequences=True, input_shape=(timesteps, features)), keras.layers.LSTM(50, return_sequences=False), keras.layers.Dense(25), keras.layers.Dense(1) ]) model.compile(optimizer='adam', loss='mse') # GRU alternative model_gru = keras.Sequential([ keras.layers.GRU(50, return_sequences=True, input_shape=(timesteps, features)), keras.layers.GRU(50), keras.layers.Dense(1) ])

🧠 RNN Variants

LSTM: Long Short-Term Memory - solves vanishing gradient problem

GRU: Gated Recurrent Unit - simpler alternative to LSTM

Bidirectional RNNs: Process sequences in both directions

NLP combines neural networks with text processing to understand and generate human language.

Embedding: Map tokens to dense vector representations

Classification/Generation: Output predictions or new text
